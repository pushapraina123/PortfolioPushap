Things I've built.

A few products I designed and shipped end to end, from schema to UI.

InfinityPlay

Full-stack platform for playing classic Flash games in modern browsers using the Ruffle emulator.

  • Integrated the Ruffle emulator to enable browser-based execution of 100+ legacy Flash games without requiring Adobe Flash Player.
  • Engineered file storage using MongoDB GridFS for SWF files and thumbnails, with Next.js API routes for upload, retrieval, categorization, voting, and issue reporting.
  • Configured JWT-based authentication and role-based access control for admins and super users.
Next.js MongoDB GridFS JWT Ruffle

ResuFit

AI-powered resume analysis platform with ATS-style scoring and personalized feedback.

  • Built 10+ RESTful APIs with Node.js and Express.js for uploads, revision history, and admin workflows, integrating Cohere AI to generate ATS scores in under 15 seconds.
  • Designed a React dashboard for resume analysis, score visualization, and revision tracking, with Firebase Auth supporting 100+ test users.
React Node.js Express MongoDB Cohere AI Firebase

ShareKare

Donation and redistribution platform connecting individual donors with NGOs.

  • Architected role-based dashboards for donors, NGOs, and administrators, reducing donation moderation time by 25% across 3 access levels.
  • Integrated Leaflet Maps for location-based donation discovery within a 10km radius, with calendar invites and live notifications — +30% engagement in testing.
Django HTML5 CSS3 SQLite Leaflet Maps
